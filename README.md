### Описание
![Mars](https://github.com/Sunl1t/flutter-labs-smekalov/blob/master/head.jpg)
Kitten Clicker — мобильное приложение на Flutter, вдохновленное idle-играми. 
Пользователь кликает на изображение котенка, чтобы заработать "клики", которые можно обменять на монетки. 
Монетки тратятся на покупку скинов (разных изображений котенка) или новых котят в коллекцию. 
MVP фокусируется на базовом кликинге, магазине и коллекции, с использованием публичного API для 
загрузки изображений котят. 

### Основные функции
Клик по котенку для накопления "кликов".
Обмен кликов на монетки (1:10 соотношение).
Магазин: покупка скинов (изменение изображения котенка) или 
новых котят для коллекции (цена растет с каждой покупкой).
Коллекция: отображение купленных котят.
Загрузка случайных изображений котят из публичного API (The Cat API).
Временное хранение данных в памяти, затем в SharedPreferences.

-Счетчики кликов и монеток.
Нижняя навигация: кнопки "Магазин" и "Коллекция".

### Навигация
Используется MaterialApp с Navigator для переходов.
BottomNavigationBar на главном экране для переключения между "Магазин" и "Коллекция" (без полного перехода, stateful widget).
Кнопка "Назад" (AppBar) для возврата на главный экран.
Простые маршруты: '/' — Home, '/shop' — Shop, '/collection' — Collection.

### Сценарии использования

1. Запуск и кликинг:
Пользователь открывает главный экран, затем кликает на котенка и ему прибавляется +1 на его счетчике кликов.
Если достаточно кликов, то переходит в магазин, нажимает "Обменять" и меняет их на монетки.

2. Покупка в магазине:
С главного экрана переходит в магазин (кнопка навигации). Выбирает скин/котята и если монет хватает, то покупает (из монеток вычитается цена, добавляется в коллекцию, обновляется текущий скин/котенок).
Возвращается назад.

3. Просмотр коллекции:
Переходит в коллекцию и видит список купленных. Может выбрать котенка для установки как текущий или скин.
